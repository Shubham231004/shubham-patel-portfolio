# Shubham Patel — Portfolio

Personal portfolio built with Next.js and TypeScript.

## Local development

```bash
pnpm install --frozen-lockfile
pnpm dev
```

## Production

Production builds require `NEXT_PUBLIC_SITE_URL`.

```bash
NEXT_PUBLIC_SITE_URL=https://patelshubham.com
pnpm build
pnpm start
```
